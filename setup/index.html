Setup guide for HubSpot users

This is the public setup guide for the HostMyText app in HubSpot.

What the app does

Section titled “What the app does”

Send and receive SMS and MMS with your HostMyText numbers from HubSpot.

Conversations appear in the HubSpot inbox and on the contact’s timeline.

Reps text from a card on the contact record.

Workflows send messages with the “Send HostMyText message” action.

Opt-out status stays in sync between HostMyText and HubSpot.

The app is for use in the United States only.

What you need

Section titled “What you need”

In HubSpot

Section titled “In HubSpot”
  • Sales Hub Professional or higher, or Service Hub Professional or higher.
  • A HubSpot Super Admin to install the app. A user with Marketplace access and the right permissions also works.

Marketing Hub alone, Starter plans and Free plans cannot install the app.

In HostMyText

Section titled “In HostMyText”
  • A HostMyText organization.
  • A HostMyText organization admin to sign in during the install.
  • At least one HostMyText number.

One HubSpot account links to one HostMyText organization.

One HostMyText organization links to one HubSpot account.

Get started

Section titled “Get started”

To get the install link, contact HostMyText: https://www.hostmy.com/get-support

Install

Section titled “Install”
  1. Open the install link.
  2. Choose your HubSpot account if HubSpot asks.
  3. Review the permissions on the HubSpot screen.
  4. Click Connect app.
  5. HubSpot shows a dialog for apps that it has not reviewed. Type “I accept the risk” and continue.
  6. Sign in to HostMyText as an organization admin.
  7. The page “Your HubSpot account is connected” appears.

HubSpot shows a warning and a dialog for every app that it has not reviewed.

Set up

Section titled “Set up”

Do these steps in order.

  1. Add the Send SMS card. Open the Contacts page. Click Customize, then Default View, then Add card, then Card Library. Search for Send SMS. Add the card.
  2. Link your seat. Open a contact. Open the Send SMS tab. Link your HostMyText login in the window.
  3. Turn off HostMyText auto-replies on each number that you connect. If you keep them on, a contact can get two replies.
  4. Connect your numbers. Click the Marketplace icon, then Connected apps, then HostMyText, then Settings. In Phone numbers, click Connect next to each number.
  5. Choose the automation sender. In Automation sender, choose a linked user and click Save.
  6. Build a workflow. Add the action Send HostMyText message. Find it in the category Integrated Apps.

Each rep links the HostMyText login one time.

Use the app

Section titled “Use the app”
  • Send a text from the Send SMS tab. Choose From, check To, type the message, click Send.
  • Send one picture (PNG or JPEG) with the text.
  • Reply to a conversation in the HubSpot inbox. HostMyText sends the reply as a text.
  • Download the SMS history of a contact as a CSV file.
  • Use these tokens in workflow messages: {{firstname}}, {{lastname}}, {{email}}, {{phone}}, {{mobilephone}}, {{company}}, {{jobtitle}}.

Limits

Section titled “Limits”
  • Bulk campaigns do not appear in HubSpot.
  • Group messages do not appear in HubSpot.
  • Messages from before you connected the app do not appear in HubSpot.
  • The HubSpot inbox has no button to start a new conversation with this app. Start from the card on the contact record.
  • HubSpot has no “Delivered” status for this app. If the carrier reports a failure, HubSpot changes the message to FAILED.
  • The history file contains SMS messages only, as HubSpot shows them.

Opt-outs

Section titled “Opt-outs”

HostMyText controls opt-outs.

HostMyText checks the opt-out status before each text.

The app copies the status to HubSpot contact properties.

A change to these properties in HubSpot does not change the opt-out.
